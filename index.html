Paramètres de réception

Numéro de réception choisi pour les demandes DANI. Vous pouvez le tester ci-dessous.

Le numéro est enregistré dans ce navigateur. Le bouton de test ouvre WhatsApp avec un message préparé, sans l’envoyer automatiquement. Avant publication, le numéro devra être configuré côté serveur ou dans une version administrateur sécurisée. Ne saisissez pas de données bancaires ici.

Sauvegarde des données

Exportez une copie des annonces et demandes enregistrées sur ce navigateur.

La sauvegarde comprend les véhicules, leurs photos enregistrées localement, les demandes de réservation et le numéro WhatsApp configuré. Elle ne comprend aucune donnée de commission ni de virement aux propriétaires.

Attention : restaurer une sauvegarde remplace les annonces et demandes locales actuelles. Téléchargez d’abord une copie si vous souhaitez les conserver. Ces données restent dans ce navigateur ; cela ne les synchronise pas entre plusieurs appareils.
